## API 调用需求估算

基于以上统计，Step 6 填值阶段需要调用 API 的叶子数量：

| 类型 | 叶子数 | 说明 |
|------|--------|------|
| 文本 pos（text_pos）| ~3,075 | 需 DeepSeek 提取语义关键词 |
| 文本 neg（text_neg）| ~1,579 | 跨商品采样为主，少量 fallback |
| 图像 pos（image_pos）| ~2,189 | 需 Gemini 看图生成描述 |
| 图像 neg（image_neg）| ~1,155 | 跨商品采样为主，少量 fallback |

> 实际 API 调用次数取决于 lookup table 覆盖率，预计 text_pos + image_pos 约 5,264 次调用（对应涉及的 unique gold 商品数）。
