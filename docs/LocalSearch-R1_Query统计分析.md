## API 调用需求估算

基于以上统计，Step 6 填值阶段需要调用 API 的叶子数量：

| 类型 | 叶子数 | 说明 |
|------|--------|------|
| 文本 pos（text_pos）| ~3,075 | 需 DeepSeek 提取语义关键词 |
| 文本 neg（text_neg）| ~1,579 | 跨商品采样为主，少量 fallback |
| 图像 pos（image_pos）| ~2,189 | 需 Gemini 看图生成描述 |
| 图像 neg（image_neg）| ~1,155 | 跨商品采样为主，少量 fallback |

> 实际 API 调用次数取决于 lookup table 覆盖率，预计 text_pos + image_pos 约 5,264 次调用（对应涉及的 unique gold 商品数）。

## 空 GT 原因分析

### 空 GT 按 Level

| Level | 电商空GT | 邮件空GT |
|-------|---------|---------|
| Level 1 | 0（0%）| 412（5.2%）|
| Level 2 | 710（8.9%）| 1,582（19.5%）|
| Level 3 | 807（20.1%）| 1,178（29.8%）|

- 电商 Level 1 无空 GT（单叶子必有 gold）
- 邮件 Level 1 空 GT 5.2%，主因：向量检索 TOP_K=20 未覆盖 gold（文本/向量匹配精度限制）
- 随 Level 增大，多条件 AND 交集缩小，空 GT 率显著上升

## GT 过大（>500）原因分析

### 电商 GT>500 主要字段

| 字段 | 出现次数 | 原因 |
|------|---------|------|
| average_rating | 2,496 | 值域 1.0–5.0，步长 0.1，一个值可命中大量商品 |
| category | 2,048 | 类别粒度粗，单类别商品数多 |
| text | 1,044 | 向量检索 TOP_K=20 候选集宽泛，OR 结构扩大 |
| price | 1,042 | 区间 [×0.95, ×1.05] 在热门价格段命中过多 |

### 邮件 GT>500 主要字段

| 字段 | 出现次数 | 原因 |
|------|---------|------|
| Date | 989 | 年份粒度（1998–2003），单年邮件量可达数百 |
| Message | 361 | OR 结构 + 文本相似度宽泛 |

## 结论与改进方向

| 问题 | 数据集 | 严重程度 | 建议 |
|------|--------|---------|------|
| GT>500（占 21%）| 电商 | 中 | `average_rating` 考虑加范围约束；`category` 可与其他字段强制 AND |
| 空GT（占 15.9%）| 邮件 | 中 | 提高向量检索 TOP_K（20→50）；或降低多条件 AND 严格度 |
| 邮件 Level1 空GT（5.2%）| 邮件 | 低 | Message 字段单独检索精度不足，可提升 embedding 质量 |
