LocalSearch-R1：通过强化学习实现检索程序合成

训练轻量级 LLM，通过强化学习和可执行 DSL 程序，实现对本地异构数据的混合检索编排。

核心洞察

现有的 RL 检索方法（Search-R1、DeepRetrieval）将 LLM 定位为 查询生成器 — 模型只优化"问什么"，而"怎么找"完全交给外部搜索引擎。当面对本地环境中结构化元数据 + 非结构化文本 + 图像三种异构数据源的复杂逻辑组合需求时（交集、并集、否定、嵌套），纯文本查询或 boolean 查询的表达能力远远不够。

LocalSearch-R1 将 LLM 的角色从查询生成器升级为 检索编排器 — 模型生成的不是一个查询字符串，而是一个可执行的 DSL 程序，融合 SQL 逻辑表达能力与向量检索语义匹配能力，实现对多条异构检索路径的任意逻辑组合。

DSL 示例 — 电商多模态查询

用户查询: "找一双红色的跑步鞋，价格在 50-100 美元之间，评分 4 星以上，材质要透气的"

-- 由 RL 训练的 Qwen3-4B 生成
{
  "sql": "SELECT product_id FROM products
         WHERE price BETWEEN 50 AND 100
         AND average_rating >= 4.0
         AND product_id IN <vector_0>
         AND product_id IN <vector_1>
         ORDER BY average_rating DESC LIMIT 20",
  "vector_query_list": [
    "red running shoes breathable material",  // <vector_0> → 文本 embedding 检索
    "red athletic sneakers"                       // <vector_1> → 图像 embedding 检索
  ]
}

执行流程：vector_0/1 先经向量索引召回候选 ID → 注入 SQL 占位符 → SQL 引擎执行结构化过滤 + 逻辑组合 → 返回结果。SQL 的完备逻辑运算（AND/OR/NOT/嵌套）自然成为多路检索的编排骨架。

方法概述

训练流程

第一阶段 — SFT 热身： 在 18K+ 条 (query → DSL) 标注数据上微调 Qwen3-4B，使模型学会 DSL 基础格式。SFT loss 降至 0.053，格式通过率 100%。

第二阶段 — RL（GRPO / DAPO）： 使用复合奖励函数进行强化学习优化。模型在本地执行环境中生成 DSL → 执行 → 获得奖励反馈，学会生成更精准的检索编排程序。

复合奖励函数
组件信号权重目的
Sf 格式JSON 可解析、SQL 语法正确0.1语法正确性
Se 执行SQL + 向量检索执行成功0.3执行可靠性
Sr 结果Hit@1 / Hit@3 匹配1.0检索精度
Sl 长度惩罚冗长输出0.05响应效率

层次化设计：可解析 → 可执行 → 结果正确 → 响应高效。相比 Search-R1 和 DeepRetrieval 的单一结果匹配奖励，为可执行程序生成提供更丰富的学习信号。

两个评测场景
电商场景（Amazon）

结构化字段 (price, rating, brand, category) + 文本描述 + 产品图像。3000 条测试查询，3 个复杂度级别，3 种模态。

邮件场景（Enron）

结构化字段 (sender, date, labels, read status) + 邮件正文。3000 条测试查询，3 个复杂度级别。典型的隐私敏感本地检索场景。

核心发现

1

RL 远超商业大模型（双场景验证）：电商 GRPO=0.809 vs GPT-5.5=0.667 (+14.2pp)；邮件 DAPO=0.909 vs GPT-5.5=0.855 (+5.4pp)。4B 本地模型全面超越前沿大模型。

2

DSL 动作空间 >> 文本/布尔查询：我们的 RL (0.809) vs 相同基座模型的 DeepRetrieval RL (0.638) = +17.1pp。多模态 DSL 的表达能力是关键差异化因素。

3

RL 超越所有检索范式：我们的 RL (0.809) > RankGPT (0.742) > DeepRetrieval (0.638) > BGE-Reranker (0.593) > BM25 (0.548)。检索编排器范式一致性地优于查询生成器和固定流水线。

4

RL 学会了动态编排：图像模态从 SFT→RL 提升 +39.6pp，表明模型学会了有效组合图像向量检索路径，这是仅靠 SFT 无法掌握的能力。
